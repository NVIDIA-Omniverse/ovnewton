Read field reference#

This page lists every field that StageBinding.read() accepts. It is generated from the same declarations as the runtime and ovnewton.read_fields(). Tests check each declaration against actual reads.

Conventions#

  • Newton fields. A snake_case name, such as joint_q or joint_target_ke, is the name of a Newton array. It returns Newton’s values unchanged: Newton’s units, frames, body order and component order. The application owns any conversion.

  • Standard fields. A camelCase name, such as position or jointPosition, is a standard field. Per-axis joint fields use the units of the matching USD joint attributes: degrees on angular axes, and the authored body order. All other values keep Newton’s units. The table below lists the angular unit of each field. Each field’s Units and Conversion rows give the details. Its Newton fields row names the Newton fields that read the same Newton arrays.

  • Model units. Lengths use the model’s length unit. For a model that ovnewton builds, this is the stage’s length unit. Mass uses the model’s mass unit. Time is in seconds.

  • Rows. Each group lists its prims in prim_list. For prim i, read row column.data_row_index(i) of the column’s tensor.

  • Readiness. On CUDA, wait for column.cuda_sync.wait_event before reading on another stream. On CPU, data is ready when read() returns.

  • Discovery. ovnewton.read_fields() returns these declarations as ReadField objects. ovnewton.attributes.list_attributes() and get_attribute() look them up by object type.

  • Unit terms. Each field’s Unit terms row gives its units as powers of mass, length, time and angle. For example, length time^-1 is a velocity. A term covers all values, the linear_axes or angular_axes of a joint, or named components. Joint fields give a linear term and an angular term. Angular terms name their angle unit, radians or degrees. An empty row means the values have no units. A quaternion term has no dimensions: its four XYZW components are not angles. translation is the three XYZ coordinates of a free or distance joint.

  • Joint layouts. Newton’s joint_q packs a different row for each joint type. Its Joint layouts row lists the parts of the row, in order, for each joint representation. Each part names the unit term that applies to it. configured means the number of scalar axes that a D6 joint enables. The live joint’s type chooses the layout.

  • Frame tags. A field’s Frame tag is a short form of its Frame row: world; body (the body’s origin frame); com (the body frame at the center of mass); or joint (the parent joint frame, which also defines the joint axes). Exceptions are in the Frame row.

Angular units#

The angular unit depends on the quantity. The name does not state the unit.

Quantity

Fields

Angular unit

Body angular velocity and acceleration

angularVelocity, angularAcceleration, rootAngularVelocity, body_qd, body_qdd

Radians per second, or per second squared. Not converted.

Joint positions, velocities and targets

jointPosition, jointVelocity, jointPositionTarget, jointVelocityTarget

Degrees, or degrees per second, as in USD.

Joint limits

jointLimit, jointMaxVelocity

Degrees, or degrees per second, as in USD.

Joint drive gains

jointStiffness, jointDamping

Per degree, or per degree per second, as in USD.

Joint efforts and armature

jointMaxForce, jointFriction, jointArmature, joint_f, joint_effort_limit, joint_friction, joint_armature

Torque, or moment of inertia. Not converted.

Newton joint fields

joint_q, joint_qd, joint_target_*, joint_limit_*, joint_velocity_limit

Radians, radians per second, or per radian, as in Newton.

Joint fields that use degrees also follow the authored USD body order (physics:body0 to physics:body1) where the quantity has a sign. Linear axes are never converted.

Storage and lifetime#

Storage

Meaning

borrowed

A read-only view of the Newton array, with no copy. It can include unselected rows; use the column’s row map. It shows later writes to that array. Do not change the array until every reader has finished.

gathered

A new buffer that this read fills on the model device. It holds a copy and does not change afterwards. It stays valid while the result, a group, a column or one of its DLPack objects is alive.

borrowed_or_gathered

Borrowed when the selected joints share one width and their source rows line up. Otherwise gathered.

query_owned

Computed once when the query was created. It does not change between reads.

Device

Meaning

The connected model’s device.

joint_q#

Newton joint coordinates.

Property

Value

Objects

joint

Identity

The bound joint prim. Fixed joints have no coordinates and produce no row.

Source

State.joint_q

Standard fields

jointPosition

Requires

state

Values

Variable × float32. The joint’s coordinate count, from Model.joint_q_start. Joints with different counts produce separate columns.

Layout

Newton’s coordinate order for the joint type. Ball joints store an XYZW quaternion. Free and distance joints store XYZ, then an XYZW quaternion. D6 joints store linear coordinates before angular ones.

Units

Linear coordinates in model length units. Angular coordinates in radians. Quaternions have no units.

Unit terms

linear_axes: length; angular_axes: angle, angle in radians; translation: length; quaternion: ``.

Joint layouts

prismatic: linear_axes × 1; revolute: angular_axes × 1; ball: quaternion × 4; free: translation × 3, then quaternion × 4; distance: translation × 3, then quaternion × 4; d6: linear_axes × configured, then angular_axes × configured.

Frame

Newton joint frames: the child joint frame relative to the parent joint frame.

Frame tag

joint

Conversion

None. Values are Newton’s.

Storage

borrowed_or_gathered

Device

model
