Attachment#

ovnewton.register_usd_schemas()#

Register ovnewton’s USD schemas before the first USD schema read.

Registration is process-wide, irreversible, and safe to repeat. It must run before any USD schema definitions are read in the process, including by an ovstage population or export call.

Return type:

None

ovnewton.population_desc()#

Select physics data and composed API-schema names for ovnewton imports.

Use with population.open_usd_with_desc (or its string variant), alongside any rendering descriptors. This preserves unregistered schema names and supported MuJoCo joint and equality parameters, allowing the importer to identify equalities and detect unsupported physics. It also resolves physics materials and collision-group collections while the USD stage is available. It does not register plugins or repopulate a stage; call ovnewton.register_usd_schemas() before the first population operation.

Return type:

population.Desc

ovnewton.add_ovstage(builder, ovstage_stage, *, ordinal=1)#

Add one populated ovstage’s model data to a caller-owned Newton builder.

The current implementation supports one ovstage per builder. builder must not contain model entities, but its defaults and custom attribute definitions may be configured. This function applies the stage’s up axis and gravity, adds the stage-backed entities, and returns without finalizing the builder or creating a StageBinding. Callers may perform solver-specific preparation afterwards.

Populate USD inputs with ovnewton.population_desc() (or an equivalent descriptor) so unsupported authored API names survive schema population. This function cannot detect names discarded before import.

Supported surface cloth retains its publication mappings through Newton’s custom model attributes. For VBD cloth, call builder.color(include_bending=True) before finalization, then bind the finalized model with attach_ovstage(stage, model=model).

ordinal bounds the populated payloads read from the stage. The returned metadata reports whether preserving rootless joints requires skipping Newton’s articulation-membership validation during finalization.

Parameters:

  • builder (newton.ModelBuilder)

  • ovstage_stage (ovstage.Stage)

  • ordinal (int)

Return type:

ovnewton.attach_ovstage(ovstage_stage, *, model=None, ordinal=1)#

Create a StageBinding for an ovstage and a Newton model.

When model is supplied, this function binds it without importing or finalizing anything. Its body_label and joint_label values must match prim paths in the ovstage.

When model is None, this function creates a newton.ModelBuilder, adds the ovstage contents, finalizes the model, and binds it. Call add_ovstage() directly when the application needs to configure the builder before finalization.

For imports, populate USD inputs with ovnewton.population_desc() or an equivalent descriptor to preserve unsupported authored API names.

ordinal bounds the populated payloads used to build or validate the binding and defaults to the conventional initial population ordinal, 1. Ovstage does not retain historical payloads.

Parameters:

  • ovstage_stage (ovstage.Stage)

  • model (newton.Model | None)

  • ordinal (int)

Return type:

StageBinding

class ovnewton.StageBinding(stage, model, *, ordinal=1)#

Connect a Newton model to an ovstage through the model’s body and joint labels.

Writes simulation state to ovstage, reads stage changes into Newton, and lets applications read selected Newton state or model arrays. Writes run one at a time because they reuse buffers. A read may borrow arrays from its supplied state or from the bound model; do not change those arrays until every reader has finished. Recreate the binding after changing the model or stage structure.

Parameters:

  • stage (ovstage.Stage)

  • model (newton.Model)

  • ordinal (int)

property model: newton.Model#

The connected newton.Model.

query(
stage_query=None,
*,
paths=None,
object_type=None,
scope=ObjectScope.ALL,
)#

Prepare a reusable output selection from a stage query or paths.

Pass either stage_query or paths, but not both. When object_type is provided, both may be omitted to select every object of that type. Paths must be unique absolute paths. Bound bodies, articulation roots, the effective physics scene, and authored joints use stage prim paths; generated Newton joints may use model-only labels. Read results keep body order and preserve joint order within each returned group. Each column has one width; columns with the same ordered prim rows share a group. A stage query may also match unrelated prims; those prims are ignored. ObjectScope.ALL is supported. Active and changed-since membership are not yet supported. The returned selection remains valid after the stage query is closed.

Query.attributes lists candidate field-name tokens for this topology, not sample-time availability. Optional state/control buffers are validated by read(). Keep this selection with its originating binding. Structural changes require a new binding and new selections; no automatic topology-invalidation token is provided.

Parameters:

  • stage_query (ovstage.Query | None)

  • paths (Optional[Sequence[str]])

  • object_type (SimObjectType | None)

  • scope (ObjectScope)

Return type:

Query

read(state=None, *, control=None, query=None, attributes)#

Expose selected Newton output as prim groups with attribute columns.

state must provide any requested state arrays. Their sizes must match the connected model, and they must use the same device. It may be omitted when only model or control attributes are requested. control supplies current joint targets and commanded effort, and is required when either is requested for selected joints. If query is omitted, the read includes every available output object. attributes accepts the fields listed in Read field reference, which ovnewton.read_fields() also returns as ReadField declarations: body pose, velocity, optional acceleration, mass-property, shape-material, articulation-root and scene fields, Newton joint fields such as joint_q, joint_qd and joint_f, and standard per-axis joint fields such as jointPosition. joint_f reads commanded generalized forces from Control in velocity-DOF order, not measured solver forces. Names or interned token IDs are accepted; duplicate requests are collapsed. An unknown field is an error; a known field with no compatible selected objects returns no column. An empty attribute list returns an empty result. Discovery does not validate optional state buffers; requesting unavailable acceleration, for example, raises ValueError. No solver work or state reconstruction is performed.

Newton fields have snake_case names, which are Newton array names. They keep Newton’s units, frames and component order. joint_q uses generalized coordinates (including XYZW quaternions), while joint_qd uses velocity DOFs; their widths can differ. Standard fields have camelCase names. On angular joint axes, positions, velocities, targets and limits are in degrees or degrees/s, gains are per degree, and efforts are not converted; these fields follow the authored body order. Body angular velocity stays in radians/s. Reads preserve model length units and do not normalize to SI.

Each group identifies shared prim rows; its columns hold the requested attributes, independent row mappings and CUDA readiness. Native body columns and compatible single-width joint columns refer directly to arrays from state, control or the connected model and may include unselected storage rows plus a row map. A joint selection borrows only when it has one width and compatible source-offset alignment; mixed widths or incompatible offsets require a device gather. Split body/root fields, materials and converted joint fields allocate output on the model device. See Read simulation output for the per-field contract. Use each column’s data_row_index(i) or data_index_dlpack() to locate logical prim i. Do not mutate borrowed state, control or model arrays until every reader has finished.

CPU data is ready when this method returns. On CUDA, call this method on the Warp stream that last wrote the requested state, control or model arrays, or first make the current stream wait for that work. CUDA work does not block the CPU; a reader on another CUDA stream must wait for column.cuda_sync.wait_event. Retain the result, group or column through consumer completion. The event reports producer readiness, not consumer completion. Borrowed results are live views, so state-buffer reuse, control writes such as Control.clear() or model edits require coordination with every reader; copy explicitly for history. Results need no explicit release, and their zero-valued ordinal metadata does not identify a simulation tick.

Parameters:

  • state (newton.State | None)

  • control (newton.Control | None)

  • query (Optional[Query])

  • attributes (Sequence[str | int | ovstage.Token])

Return type:

ReadResult

write(values, *, control, query)#

Replace selected native scalar joint targets without stage writes.

Supported names are joint_target_q and joint_target_qd. Values are one-dimensional float32 Warp arrays on the model device. The query must select only scalar articulation joints. Rows follow the corresponding public read’s logical prim order, not its storage rows. Values use Newton’s native units and signs, including radians, with no USD conversion.

All input shapes, dtypes and finite values are checked before mutation. Payloads stay on the device; only a validation flag is read on the host. Inputs are copied and may be reused after return. Unselected values survive. Calls are synchronous and cannot run during CUDA graph capture. Use the producer’s stream or establish a stream dependency first. The application owns solver configuration and step ordering. No state, forces, model properties or topology are changed.

Parameters:

  • values (Mapping[str, wp.array[Any]])

  • control (newton.Control)

  • query (Query)

Return type:

None

update_to_ovstage(state, *, ordinal)#

Write the current Newton state to ovstage at ordinal.

Body world poses are written through omni:xform with omni:resetXformStack enabled. This also writes body velocities and supported one-axis joint positions and velocities. The writes finish before this method returns. Call stage.advance_write_floor(ordinal) to make them visible to readers.

Raises ValueError if an array has the wrong size or device.

Parameters:

  • state (newton.State)

  • ordinal (int)

Return type:

None

update_from_ovstage(
state,
control,
*,
ordinal=None,
attributes=None,
)#

Apply sealed state and drive targets from ovstage.

With attributes=None (the default), read all supported body/joint state and drive targets. Body poses include ancestor transforms. Select any combination of body_q, body_qd, jointPosition, jointVelocity, jointPositionTarget, and jointVelocityTarget to update only those fields. Joint fields cover existing single-DOF channels; other coordinates and unselected arrays stay unchanged. Explicit selections do not run forward/inverse kinematics or reconcile body and joint state. Use the default full resync for body-derived joint coordinates. An empty selection is a no-op; unknown names are rejected.

Joint angular values convert from stage degrees to Newton radians; linear values retain the stage’s length units. If ordinal is omitted, read the latest sealed values. An explicit ordinal is a consistency ceiling, not a request for historical payloads.

Raises ovnewton.OvstageContractError if the stage cannot provide one consistent set of values.

Parameters:

  • state (newton.State)

  • control (newton.Control)

  • ordinal (int | None)

  • attributes (Sequence[str] | None)

Return type:

class ovnewton.ReadResult(groups)#

Read-only output groups from one read.

A result may refer to arrays from the state or model used by StageBinding.read() instead of a copy. Borrowing depends on the selection and layout; derived and gathered columns own per-read buffers. Retention preserves allocation lifetime, not a snapshot of borrowed values. Keep source arrays unchanged and retain the result until consumers finish.

Its metadata does not identify a simulation step. Results need no explicit close or release. Managed DLPack exports retain their columns independently. This object is returned by StageBinding.read() and is not constructed directly. See Read simulation output for storage and synchronization rules.

Parameters:

groups (tuple[ReadGroup, ...])

class ovnewton.ReadGroup(storage, *, prim_list, prim_count, columns)#

Shared logical prim rows and their read-only attribute columns.

Resolve prim_list through the stage’s path dictionary. Row i names the same prim in every column, but each column has its own tensor layout and data_row_index(i). Columns are ordered by the requested attributes. object_type is the query’s filter, or None for an unfiltered query.

Unlike an OVStage read, this result does not pin stage storage and needs no explicit release. Keeping a group, column or managed DLPack export alive retains the required Newton storage, query and CUDA event. Borrowed values remain live; retain results and prevent source writes until consumers finish. Construct groups through StageBinding.read(), not directly.

class ovnewton.ReadColumn(
storage,
*,
attribute,
data_count,
tensor,
data_indices=None,
data_index_tensor=None,
)#

One read-only attribute aligned to its group’s logical prim rows.

This object is returned in ReadGroup.columns and is not constructed directly.

attribute is an interned field-name token. data_row_index(i) maps logical prim i in the group to this column’s storage row; the tensor can include unselected rows. Each column has one packed DLTensor with shape (storage_rows,) and dtype.lanes scalar components per row. Columns in different groups can have the same attribute with different widths. Values are float32 except int32 shapeCount; an optional uint32 data-index tensor provides the row map on the payload device.

Keeping the column alive retains its data, query and readiness event, but does not freeze borrowed values. Prevent source writes until consumers finish. CPU data is ready on return from StageBinding.read(); a CUDA consumer on another stream must wait for cuda_sync.wait_event. Retain the column through asynchronous consumer completion. ordinal, semantic and meta are zero placeholders, not sample or representation identifiers.

class ovnewton.attributes.UnitTerm(scope, dimensions, angle_unit=None)#

The unit of some values in a field, as powers of base dimensions.

dimensions is a tuple of (name, exponent) pairs. The names are mass, length, time and angle. For example, a velocity in length units per second is (("length", 1), ("time", -1)). Length and mass use the model’s units. Time is in seconds.

Parameters:

  • scope (str | tuple[str, ...])

  • dimensions (tuple[tuple[str, int], ...])

  • angle_unit (Literal['radian', 'degree'] | None)

scope: str | tuple[str, ...]#

The values this term covers. "all" covers every value in a row. "linear_axes" and "angular_axes" cover the scalar joint axes of that kind. "translation" covers the three XYZ coordinates of a free or distance joint. "quaternion" covers the four XYZW components of a ball, free or distance joint. It has no dimensions, so its components are not angles. "linear_components" and "angular_components" cover the linear and angular parts of a spatial vector. A tuple names components.

angle_unit: Literal['radian', 'degree'] | None = None#

"radian" or "degree" when dimensions include angle, else None.

Errors#

exception ovnewton.InvalidPhysicsError#

The populated stage contains malformed or contradictory physics data.

exception ovnewton.UnsupportedPhysicsError#

The stage uses physics semantics that ovnewton does not implement.

This is reserved for semantics whose loss would materially change physics and for which ovnewton has no exact representation or safe import policy.

exception ovnewton.OvstageContractError#

Ovstage returned data that violates the transport contract ovnewton consumes.
